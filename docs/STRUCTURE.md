# خريطة المجلدات (`src/`)

| المجلد | ماذا يوجد فيه |
|---|---|
| `src/app/` | (فارغ حالياً) غلاف التطبيق ومنطق الإقلاع. يُنقل إليه جزء من `App.tsx` في TASK 0.5b |
| `src/engine/` | محرك المحاكاة `engine.ts` ومسار A* `pathfinding.ts` |
| `src/validation/` | مدقق السيناريوهات `validator.ts` |
| `src/core/` | أنواع البيانات المشتركة `types.ts`، والكاميرا، والمخرج السينمائي، والكتالوج، واختبارات الأساس |
| `src/renderer/` | عارض PixiJS والصوت المولّد `soundSynth.ts` |
| `src/panels/` | اللوحات الجانبية: الشريط الجانبي، ولوحة الوحدات، ولوحة الأدوات، وشريط أوامر الوحدة، ولوحة معلومات الدولة، وبانيّ الحزم |
| `src/modals/` | النوافذ المنبثقة: مواصفات السيناريو، ومحرر الدولة، ودليل الدول |
| `src/packs/` | حزم الخرائط والوحدات، والتحقق منها، وتسجيلها |
| `src/countries/` | بيانات الدول وتعريفاتها واختيارها |
| `src/maps/` | محرك الخرائط الجغرافية |
| `src/storage/` | قاعدة بيانات IndexedDB |
| `src/content/` | محمّل المحتوى ومخطط التحقق منه (ينتظر TASK 1.2 ليُربط بالتطبيق) |
| `src/scenarios/` | سيناريوهات YAML المدمجة (تُنقل إلى `content/` في TASK 1.4) |
| `src/index.css`، `src/main.tsx`، `src/types-external.d.ts` | نقطة الدخول والأنماط وأنواع خارجية |
