# TASK 0.5 — تقسيم المشروع إلى مجلدات واضحة

> بطاقة مسودة: تُراجع قبل التنفيذ، ولا تُنفَّذ قبل إغلاق TASK 0.4.

**المرحلة:** 0 | **الفرع:** `task/0-5` | **المنفّذ:** منفّذ واحد يحدده المالك | **يعتمد على:** TASK 0.4

## الهدف
تقسيم الملفات الكبيرة إلى مجلدات حسب المسؤولية، بحيث يفهم أي مطوّر مكان كل شيء من أسماء المجلدات، دون أي تغيير في السلوك.

## المطلوب
1. جرد الملفات الكبيرة: `src/App.tsx` (~1700 سطر)، و`src/renderer/studioRenderer.ts` (~2500 سطر)، و`src/components/CountryEditorModal.tsx` (~1100 سطر)، و`src/core/engine.ts` (~1160 سطر)، و`src/core/validator.ts` (~1030 سطر). سجّل الأرقام الفعلية في التقرير.
2. أنشئ هيكل المجلدات التالي وانقل الملفات إليه، دون تغيير المحتوى المنطقي:
   - `src/app/` لمكونات الغلاف والتنسيق الرئيسي (من `App.tsx`).
   - `src/editor/` لمحرر السيناريو والحالة المرتبطة به.
   - `src/panels/` للوحات الجانبية (من `components/`).
   - `src/modals/` للنوافذ المنبثقة.
   - `src/engine/` (من `src/core/` ما يخص المحاكاة)، و`src/validation/` للمدقق.
   - `src/renderer/` يبقى كما هو، مع تقسيم `studioRenderer.ts` إلى ملفات أصغر حسب الطبقة (خريطة، وحدات، تأثيرات، كاميرا).
3. أعد تصدير الدوال الحالية من أماكنها القديمة إن لزم، لتبقى الاختبارات تعمل دون تعديل كبير.
4. اكتب `docs/STRUCTURE.md` يشرح كل مجلد في سطرين.

## الملفات المسموح بتعديلها
- `src/**` (نقل وإعادة تسمية فقط)
- `docs/STRUCTURE.md`
