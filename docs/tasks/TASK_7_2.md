# TASK 7.2 — ثبات الشخصيات والبيئات

> بطاقة مسودة: تُراجع قبل التنفيذ، ولا تُنفَّذ قبل إغلاق المهمة المذكورة في «يعتمد على».

**المرحلة:** 7 | **الفرع:** `task/7-2` | **المنفّذ:** منفّذ واحد يحدده المالك | **يعتمد على:** TASK 7.1

## الهدف
كل شخصية لها هوية ثابتة في كل المشاهد، تُستدعى بالمعرّف.

## المطلوب
1. أنشئ `content/characters/<id>/` بصور مرجعية، ومعرّف صوت، ووصف ثابت.
2. اجعل كل مشهد يشير إلى معرّف الشخصية، لا إلى ملف مباشرة.
3. اكتب قائمة تحقق لثبات الشخصية في `docs/CHARACTER_CONSISTENCY.md`.
4. أضف اختباراً: شخصية واحدة تُستعمل في مشهدين تُحل إلى الأصل نفسه.

## الملفات المسموح بتعديلها
- `content/characters/**` (جديد)
- `src/content/**`
- `docs/**`

## الممنوع
- استخدام صور أو أصوات لأشخاص حقيقيين دون إذن موثّق.
- تغيير المحرك.

## معايير القبول
- الفحوص الأربعة ناجحة.
- الشخصية نفسها تُحل إلى الأصل نفسه في مشهدين.
- التقرير `docs/tasks/TASK_7_2_REPORT.md` يذكر الأوامر والنتائج وما لم يُنجز.
