# TASK 6.1 — حفظ المشروع كملفات

> بطاقة مسودة: تُراجع قبل التنفيذ، ولا تُنفَّذ قبل إغلاق المهمة المذكورة في «يعتمد على».

**المرحلة:** 6 | **الفرع:** `task/6-1` | **المنفّذ:** منفّذ واحد يحدده المالك | **يعتمد على:** TASK 5.2

## الهدف
المشروع يُحفظ ويُفتح كمجلد ملفات، لا كبيانات داخل المتصفح فقط.

## المطلوب
1. حدّد صيغة المشروع: `project.json` وسيناريوهات ومراجع أصول.
2. أضف حفظ وفتح المشروع عبر File System Access API، مع احتياط بالتنزيل والرفع.
3. أضف اختبار دورة كاملة: حفظ ثم فتح ثم مقارنة.
4. وثّق الصيغة في `docs/PROJECT_FORMAT.md`.

## الملفات المسموح بتعديلها
- `src/app/project/**` (جديد)
- `src/App.tsx` (أزرار الحفظ والفتح فقط)
- `docs/**`

## الممنوع
- حذف التخزين الحالي في IndexedDB قبل ترحيل البيانات.
- تغيير المحاكاة.

## معايير القبول
- الفحوص الأربعة ناجحة.
- الحفظ ثم الفتح يعطيان المشروع نفسه.
- التقرير `docs/tasks/TASK_6_1_REPORT.md` يذكر الأوامر والنتائج وما لم يُنجز.
