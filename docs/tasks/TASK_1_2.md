# TASK 1.2 — ربط محمّل المحتوى بالأصوات

> بطاقة مسودة: تُراجع قبل التنفيذ، ولا تُنفَّذ قبل إغلاق المهمة المذكورة في «يعتمد على».

**المرحلة:** 1 | **الفرع:** `task/1-2` | **المنفّذ:** منفّذ واحد يحدده المالك | **يعتمد على:** TASK 1.1

## الهدف
المحرك يطلب الحدث الصوتي باسمه، ويحدد المانيفست الملف، وإن غاب الملف يستخدم المولّد الحالي.

## المطلوب
1. اربط `resolveSoundEvent` من `src/content/loader.ts` بمسار تشغيل الصوت في `soundSynth.ts`.
2. أضف لكل حدث في `src/core/engine.ts` بيانات وصفية (`meta`) موجودة أصلاً، دون تغيير منطق المحاكاة.
3. عند غياب الحدث من المانيفست أو غياب الملف، يُشغَّل المولّد الحالي ويُسجَّل ذلك مرة واحدة فقط.
4. أضف اختبارات لحالات: حدث موجود، حدث غائب، ملف غائب.

## الملفات المسموح بتعديلها
- `src/content/**`
- `src/renderer/soundSynth.ts`
- `src/core/engine.ts` (الأنواع والبيانات الوصفية فقط)
- `src/core/*.test.ts`
- `docs/**`
