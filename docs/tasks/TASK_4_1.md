# TASK 4.1 — وحدات مرسومة بجودة احترافية

> بطاقة مسودة: تُراجع قبل التنفيذ، ولا تُنفَّذ قبل إغلاق المهمة المذكورة في «يعتمد على».

**المرحلة:** 4 | **الفرع:** `task/4-1` | **المنفّذ:** منفّذ واحد يحدده المالك | **يعتمد على:** TASK 3.2

## الهدف
استبدال رسومات الوحدات الأولى بأصول منتظمة الحجم والزاوية.

## المطلوب
1. اكتب مواصفة أصول في `docs/ART_SPEC.md`: الحجم، والزاوية، واتجاه الضوء، والظلال المدمجة.
2. ارسم أو اختر أصول ثلاث وحدات تلتزم بالمواصفة.
3. عدّل `studioRenderer.ts` لتحميل الأصول بالحجم المحدد.
4. أضف لقطات قبل وبعد في التقرير.

## الملفات المسموح بتعديلها
- `content/units/**`
- `docs/ART_SPEC.md`
- `src/renderer/studioRenderer.ts` (تحميل الأصول فقط)
- `docs/tasks/**`

## الممنوع
- تغيير منطق الرسم.
- استخدام أصول بترخيص غير مؤكد.

## معايير القبول
- الفحوص الأربعة ناجحة.
- ثلاث وحدات جديدة تظهر بالمواصفة، واللقطات مرفقة في التقرير.
- التقرير `docs/tasks/TASK_4_1_REPORT.md` يذكر الأوامر والنتائج وما لم يُنجز.
