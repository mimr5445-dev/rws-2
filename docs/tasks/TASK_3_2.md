# TASK 3.2 — خرائط تاريخية بطبقات زمنية

> بطاقة مسودة: تُراجع قبل التنفيذ، ولا تُنفَّذ قبل إغلاق المهمة المذكورة في «يعتمد على».

**المرحلة:** 3 | **الفرع:** `task/3-2` | **المنفّذ:** منفّذ واحد يحدده المالك | **يعتمد على:** TASK 3.1

## الهدف
خريطة واحدة بعدة فترات زمنية، يختار المستخدم الفترة.

## المطلوب
1. أنشئ مجلد `content/maps/<era_id>/` لكل فترة، بمانيفست يحدد السنة وحدود الدول المعنية.
2. أضف محدد الفترة في الواجهة، واحفظ الفترة في السيناريو.
3. أضف اختباراً لفترتين على الأقل.
4. وثّق مصادر الحدود التاريخية في `content/maps/SOURCES.md`.

## الملفات المسموح بتعديلها
- `content/maps/**`
- `src/packs/packRegistry.ts`
- `src/maps/worldGeoEngine.ts`
- `src/App.tsx` (محدد الفترة فقط)
- `docs/**`

## الممنوع
- ادعاء دقة تاريخية غير موثّقة.
- حذف الخريطة الحالية.

## معايير القبول
- الفحوص الأربعة ناجحة.
- تعمل فترتان على الأقل، وكل حدود موثقة بمصدرها.
- التقرير `docs/tasks/TASK_3_2_REPORT.md` يذكر الأوامر والنتائج وما لم يُنجز.
