# TASK 3.1 — دقة الحدود الجغرافية

> بطاقة مسودة: تُراجع قبل التنفيذ، ولا تُنفَّذ قبل إغلاق المهمة المذكورة في «يعتمد على».

**المرحلة:** 3 | **الفرع:** `task/3-1` | **المنفّذ:** منفّذ واحد يحدده المالك | **يعتمد على:** TASK 2.2

## الهدف
حدود الدول بدقة أعلى، مع ميزانية حجم واضحة.

## المطلوب
1. قارن `world-atlas` 110m بنسخة 50m، وسجّل الحجم المضغوط لكل منهما في التقرير.
2. اختر النسخة ضمن ميزانية يحددها التقرير، وثبّت إصدار الحزمة.
3. أزل الاعتماد على جلب الحدود من الإنترنت أثناء التشغيل، أو اجعله اختيارياً مع احتياط محلي.
4. أضف اختباراً يتحقق أن الدول الرئيسية موجودة بحدودها.

## الملفات المسموح بتعديلها
- `src/maps/worldGeoEngine.ts`
- `package.json` و`bun.lock` (حزمة الحدود فقط)
- `docs/**`

## الممنوع
- تغيير الرسم العام للخريطة.
- إضافة مكتبة رسم جديدة.

- الخريطة تعمل بلا اتصال بالإنترنت.
