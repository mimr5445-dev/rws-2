# TASK 7.1 — قالب فيديو لسلسلة تاريخية

> بطاقة مسودة: تُراجع قبل التنفيذ، ولا تُنفَّذ قبل إغلاق المهمة المذكورة في «يعتمد على».

**المرحلة:** 7 | **الفرع:** `task/7-1` | **المنفّذ:** منفّذ واحد يحدده المالك | **يعتمد على:** TASK 6.2

## الهدف
قالب يُستعمل لإنتاج حلقة تاريخية بفصول وخط زمني وطبقات خرائط.

## المطلوب
1. أنشئ `content/templates/history_episode/` يحوي فصولاً، ومساحة للتعليق الصوتي، وطبقات خرائط.
2. اكتب سيناريو تجريبياً مدته ثلاث دقائق يستخدم القالب.
3. اجعل القالب قابلاً للنسخ بتغيير الفصول والخرائط فقط.
4. صدّر الحلقة التجريبية عبر خط التصدير.

## الملفات المسموح بتعديلها
- `content/templates/**` (جديد)
- `content/scenarios/**`
- `docs/**`

## الممنوع
- كتابة محتوى تاريخي غير موثّق المصادر.
- تغيير المحرك.

## معايير القبول
- الفحوص الأربعة ناجحة.
- حلقة تجريبية مدتها ثلاث دقائق تُصدَّر بنجاح.
- التقرير `docs/tasks/TASK_7_1_REPORT.md` يذكر الأوامر والنتائج وما لم يُنجز.
