# TASK 2.2 — مزج الصوت وحفظ الإعدادات

> بطاقة مسودة: تُراجع قبل التنفيذ، ولا تُنفَّذ قبل إغلاق المهمة المذكورة في «يعتمد على».

**المرحلة:** 2 | **الفرع:** `task/2-2` | **المنفّذ:** منفّذ واحد يحدده المالك | **يعتمد على:** TASK 2.1

## الهدف
تحكم بالمستوى لكل فئة صوتية، مع حفظ الإعدادات بين الجلسات.

## المطلوب
1. أنشئ ثلاث فئات: `ui` و`sfx` و`music`، ولكل فئة مستوى مستقل.
2. احفظ المستويات في `studioDb.setSetting` وأعدها عند الإقلاع.
3. أضف تنويعاً عشوائياً بسيطاً في الطبقة والنغمة لكل تشغيل، دون التأثير على المحاكاة.
4. أضف اختباراً لحفظ الإعدادات وقراءتها.

## الملفات المسموح بتعديلها
- `src/renderer/soundSynth.ts`
- `src/storage/studioDb.ts` (إعدادات فقط)
- `src/App.tsx` (واجهة التحكم فقط إن لزم)
- `docs/**`

## الممنوع
- تغيير قاعدة البيانات أو أسماء المخازن الحالية.
- أي تأثير على المحاكاة.

## معايير القبول
- الفحوص الأربعة ناجحة.
- تبقى مستويات الصوت بعد إعادة تحميل الصفحة.
- التقرير `docs/tasks/TASK_2_2_REPORT.md` يذكر الأوامر والنتائج وما لم يُنجز.
