# ابدأ من هنا

هذا الملف هو نقطة الدخول لأي مطوّر أو نموذج أو وكيل جديد. البرومبت الموحّد لأي نموذج في `docs/AGENT_PROMPT.md`.

## ترتيب القراءة
1. `docs/HANDOFF.md`: أين وصل العمل الآن، والمهمة التالية.
2. `docs/PROGRESS.md`: سجل زمني لكل ما حدث.
3. `docs/ROADMAP.md`: كل المهام وحالتها وترتيبها.
4. `docs/PLAN.md`: القواعد والأدوار والبنية.
5. `docs/STRUCTURE.md`: خريطة المجلدات (يُنشأ في TASK 0.5).
6. البطاقة النشطة في `docs/tasks/`.

## أين تجد ماذا
| المكان | المحتوى |
|---|---|
| `docs/tasks/TASK_<رقم>.md` | بطاقة كل مهمة (ما المطلوب وما المسموح) |
| `docs/tasks/TASK_<رقم>_REPORT.md` | تقرير المهمة بعد تنفيذها |
| `docs/phases/PHASE_<n>_*.md` | ملخص كل مرحلة وحالة مهامها |
| `docs/templates/` | قالب البطاقة وقالب التقرير |
| `content/` | الوحدات والأصوات والخرائط والسيناريوهات (بيانات، لا كود) |
| `src/` | الكود |

## القاعدة الذهبية
لا تبدأ إلا بالبطاقة التي تشير إليها `HANDOFF.md`. إن كانت البطاقة مسودة أو تعتمد على مهمة غير منجزة، توقف واكتب ذلك في `HANDOFF.md`.
