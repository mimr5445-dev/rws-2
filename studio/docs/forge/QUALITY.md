# الجودة: العتبات والمراجع

## تغطية الاختبارات

- `src/core` + `src/content` + `src/render/{plan,layers,perf}`: **أسطر 93.54%** — عبارات 91.79% — دوال 91.21% — فروع 79.79% (قياس المرحلة 03، `npm run test:coverage`).
- العتبة المفروضة في `vitest.config.ts`: أسطر ≥ 92، عبارات ≥ 90، دوال ≥ 89، فروع ≥ 78. أي هبوط يفشل CI.
- `src/ui` و`src/render/pixi`: تُغطّى بـ e2e (لا متصفح محلي، ADR-0000)، ولا تُحسب في عتبة الوحدة.
- اختبارات عدم الكتابة تعمل على كائنات مجمّدة تجميداً عميقاً؛ المصفوفات النمطية (إحداثيات الدول) لا تُجمَّد في JS وتُعامل للقراءة فقط بالعقد (موثّق في `deepFreeze`).

## العتبات المفروضة الآن (مقيسة أو آلية)

- **axe:** صفر انتهاكات بمستوى `serious` أو `critical` على 390×844 و1280×800.
- **التمرير الأفقي:** `scrollWidth − clientWidth ≤ 1px` على المقاسين.
- **الحدود المعمارية:** `eslint-plugin-boundaries` صفر أخطاء، مع اختبار سلبي يُثبت أن المخالفة تفشل.
- **الحتمية:** `npm run check` صفر مخالفات في `src/core` (Math.random، Date، performance.now، setTimeout، setInterval).
- **التراخيص:** كل ملف أصل في `content/` له سجل في manifest أو بصمة داخل مجلده أو جذر مجموعته.
- **ميزانية الحزمة:** حزمة الدخول ≤ 280 ك.ب قبل الضغط، ولا يُحمَّل Pixi قبل تهيئة الخريطة (ADR-0012).
- **حتمية المحاكاة:** جدول الأحداث يُبصم في اختبار golden (`b9a7f305…`)؛ أي تغيير في الترتيب أو التوقيت يوقف CI.
- **الرسم عند الطلب:** الخريطة الساكنة لا ترسم أكثر من مرة لكل تغيّر حالة؛ يُقاس في e2e (ساكن ومتفاعل) ويُسجَّل في BUDGETS.
- **امتلاء منطقة الخريطة:** e2e يتحقق أن لوحة الخريطة تملأ منطقة الشبكة (انحدار حقيقي: 1px بسبب تعارض `relative`/`absolute`).
- **اتجاه التخطيط:** ترتيب الأعمدة يُفحص على DOM فعلياً في e2e لكل لغة، لا في الجدول وحده.
- **ثبات البصمة:** `npm run check` يقارن بصمة المشروع المرجعي في 3 عمليات منفصلة ومناطق زمنية مختلفة.
- **توقيت الصوت:** `npm run check` يفشل عند أي `setTimeout`/`setInterval`/`requestAnimationFrame` في وحدة مسارها يحتوي `audio/`؛ التوقيت من ساعة الصوت وحدها (ADR-0015).
- **سلامة الأصوات:** بصمة `sha256` وحجم كل `.wav` تطابق `content/sounds/manifest.json`، ولكل ملف سطر في `LICENSES.md`، وأي `.wav` خارج الكتالوج يفشل الفحص.
- **دقة الصوت:** اختبار الوحدة يقيس إزاحة الذروة بالارتباط المتقاطع (±1 عينة)، وe2e يقيسها في `OfflineAudioContext`، وطول المزيج = `durationTicks × 800` بفرق صفر.
