# studio-forge (v2)

مهارة لبناء استوديو الرسوم المتحركة والفيديو البرمجي من الصفر، وفق مواصفة واضحة.

## ماذا فيها

- `spec/PRODUCT_SPEC.md`: ما هو التطبيق، ولمن، وما نطاقه، وكيف يبدو، وما تعريف الاحترافية.
- `spec/ARCHITECTURE.md`: التقنيات، وهيكل المجلدات، وقواعد الاعتماد، وما لا نستخدمه ولماذا.
- `SKILL.md`: المبادئ، وخريطة المراحل والبوابات، وبروتوكول الدمج، والممنوعات.
- `phases/00` إلى `phases/13`: مهارات كل مرحلة بخطوات وتحقق ومعيار خروج.
- `templates/`: قالب تقرير البوابة، وقالب حالة المشروع.

## كيف تُستخدم

1. ضع المجلد `studio-forge/` في مسار المهارات لدى الوكيل.
2. أنشئ مستودعاً فارغاً، ثم اطلب من الوكيل تنفيذ `studio-forge`.
3. يقرأ الوكيل المواصفة أولاً، ثم ينفذ المرحلة 00، ويغلق كل بوابة بالتحقق، ويسألك قبل الانتقال.

## ملاحظة

الأرقام الهدف ليست مكتوبة عمداً. تُقاس وتُكتب في `docs/forge/BUDGETS.md`، لأن أي رقم يُكتب مسبقاً سيبقى تخميناً.
