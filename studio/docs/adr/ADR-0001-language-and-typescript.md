# ADR-0001: TypeScript الصارم كلغة المشروع

- **الحالة:** معتمد
- **المرحلة:** 00

## السياق

النموذج والأوامر والبصمة تحتاج أنواعاً تمنع الأخطاء الصامتة: معرّف مفقود، قيمة غير معرّفة، فهرس خارج الحدود.

## القرار

- TypeScript بإعداد `strict` و`noUncheckedIndexedAccess` و`exactOptionalPropertyTypes` و`noUnusedLocals`.
- الأنواع تُشتق من مخططات zod (`z.infer`) ولا تُكتب يدوياً بجانبها.
- مسار مختصر `@/*` إلى `src/*`.
- البناء عبر Vite، والفحص `tsc --noEmit` في CI قبل البناء.

## البدائل

- **JavaScript مع JSDoc:** أخف إعداداً، وأضعف في حماية النموذج.
- **Flow:** غير نشط فعلياً في النظام البيئي الحالي.

## النتائج

- أخطاء النموذج تُكتشف وقت البناء، وحدود الطبقات تُفحص بالأداة.
- تكلفة: كتابة أنواع أكثر في الواجهة والاختبارات.
