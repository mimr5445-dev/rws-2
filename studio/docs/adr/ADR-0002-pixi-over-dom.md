# ADR-0002: Pixi.js 8 للعرض بدل DOM

- **الحالة:** معتمد
- **المرحلة:** 00

## السياق

المشهد قد يحمل 150+ كياناً مع مؤثرات وكاميرا متحركة بمعدل 60 tick/ثانية. العرض بـ DOM يفرض إعادة تخطيط متكررة وقياساً داخل حلقة الإطار.

## القرار

- Pixi.js 8 على WebGL افتراضياً، وشجرة طبقات ثابتة (خريطة ← مناطق ← منشآت ← وحدات ← أسهم ← مؤثرات ← تعليقات ← واجهة المحرر).
- الطبقة تقرأ الحالة فقط؛ لا تكتب في النموذج (يفرضه `eslint-plugin-boundaries`).
- WebGPU خلف علامة بعد قياس، لا افتراضاً.

## البدائل

- **DOM/SVG:** بسيط للنص والوصول، لكنه لا يحمل المشهد الكثيف بثبات.
- **Canvas 2D مباشر:** تحكم أكبر، وفقدان شجرة المشاهد والنسيج والنصوص الغنية.
- **Three.js:** ثلاثي الأبعاد خارج نطاق v1.

## النتائج

- أداء متوقع أعلى وثبات في الإطارات.
- تكلفة: نصوص عربية داخل Pixi تحتاج ضبط دقة وتشكيلاً (المرحلة 08).
