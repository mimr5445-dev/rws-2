# ADR-0000: بيئة العمل الفعلية وانحرافها عن نص المهارة

- **التاريخ:** 2026-11-25
- **الحالة:** معتمد
- **المرحلة:** 00

## السياق

مهارة `studio-forge` تفترض مستودعاً فارغاً جديداً، وفرعاً لكل مرحلة، ودمجاً في `main`، وتشغيل Playwright محلياً على 390×844 و1280×800. الواقع في مساحة العمل هذه:

1. المستودع `mimr5445-dev/rws-2` ليس فارغاً: فيه نسخة سابقة (v0.2) في جذر المستودع، بمخططها وملفاتها.
2. الفرع الحالي `arena/1a3b060a-rws-2` ثابت، وممنوع إنشاء فروع أو الدفع إلى `main` من الجلسة.
3. لا متصفح مثبّت في الصندوق، ولا `ffmpeg`/`ffprobe`، ومصادر الشبكة المسموحة لا تشمل CDN الخاص بـ Playwright.

## القرار

1. يُبنى v1 في مجلد مستقل `studio/`، مطابق لجذر الهيكل في ARCHITECTURE §3، دون قراءة أو إعادة استخدام أي كود من نسخة v0.2. الكود السابق يبقى كما هو ولا يُحذف.
2. كل عمل المرحلة يُلتزم على الفرع الحالي، وتُفتح PR واحدة منه؛ لا دفع إلى `main`.
3. التحقق المحلي يشمل: `npm run lint` و`npx tsc --noEmit` و`npm test` و`npm run build` و`npm run check`. أما اللقطات وaxe فتُنفَّذ في GitHub Actions (حيث يمكن تثبيت Chromium)، وتُحمَّل اللقطات كـ artifacts وتُراجَع بالعين قبل إغلاق البوابة.
4. تحقق الفيديو بـ `ffprobe` (المرحلة 05) يُنفَّذ في CI حيث `ffmpeg` متاح.

## البدائل المرفوضة

- **البناء في جذر المستودع:** كان سيدمّر أو يخلط كود v0.2 بلا إذن صريح.
- **حذف v0.2 قبل السؤال:** تصرّف غير قابل للتراجع.
- **تخطي بوابة اللقطات:** يخالف المبدأ 7 (تحقق قبل الادعاء).

## النتائج

- التزام كامل بقاعدة "لا اعتماد على مشاريع سابقة" على مستوى الكود، مع بقاء النسخة القديمة كمرجع بشري.
- بوابات اللقطات أبطأ (دورة CI) لكنها حقيقية ولا تُدّعى زوراً.
- أي مرحلة تحتاج أداة غير متاحة محلياً تُوثَّق هنا قبل تجاوزها.
