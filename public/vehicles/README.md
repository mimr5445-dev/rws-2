# Real-world vehicle sprites

These isolated, photorealistic game sprites represent specific real-world models and are viewed from directly above, with the nose/gun pointing right:

- `m1a2-abrams.png` — M1A2 Abrams SEPv3 main battle tank.
- `f35a-lightning.png` — F-35A Lightning II fighter.

The images are generated renderings for the scenario studio, not documentary photographs. Transparent PNG backgrounds let the renderer rotate and place them over any map without a colored rectangle.
